# PocketSmart AI

PocketSmart AI is a Generative AI powered budget planning application.

It provides:

- Home Interior Planner
- Party Budget Planner
- Jewelry Planner
- Gemini AI integration
- Optional outfit image analysis
- User authentication
- Recommendation history
- SQLite database
- Responsive frontend
- REST APIs
- Demo fallback mode

---

# Requirements

Install:

- Python 3.11+
- VS Code
- Internet connection
- Optional Gemini API key
